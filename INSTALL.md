# Установка и настройка Lanta Camera Proxy

> Форк оригинальной надстройки [amatsnev/hass-addon-lanta-cam](https://github.com/amatsnev/hass-addon-lanta-cam), адаптированный под мобильное API `mobile.lanta-net.ru` с авторизацией по звонку и поддержкой гостевого доступа.

---

## 1. Добавление репозитория в Home Assistant

1. Откройте **Настройки** → **Приложения (Надстройки)** → **Магазин надстроек**.
2. Нажмите **⋮** (три точки) в правом верхнем углу → **Репозитории**.
3. Вставьте ссылку на этот репозиторий:
   ```text
   https://github.com/proshletsov/hass-addon-lanta-camphone
   ```
4. Нажмите **Добавить**, затем закройте окно и обновите страницу браузера (при необходимости).

---

## 2. Установка и базовая конфигурация

1. В магазине надстроек найдите **Lanta Camera Proxy** и нажмите **Установить**.
2. Перейдите на вкладку **Конфигурация**:
   - **`phone`** *(необязательно)* — ваш номер телефона, привязанный к договору ЛанТа (например, `79001234567`). Можно оставить пустым и ввести позже в веб-интерфейсе.
   - **`bearer_token`** *(необязательно)* — готовый токен авторизации (UUID без слова `Bearer`). Заполняется только если вы не хотите авторизовываться по звонку.
   - **`house_id`** *(необязательно)* — ID вашего дома (или несколько ID через запятую, например `7629, 7630`). **Оставьте пустым при первом запуске** — надстройка попробует определить его сама.
   - **`refresh_interval`** — интервал обновления ссылок и токенов камер в секундах (по умолчанию `5400` = 1.5 часа, менять не рекомендуется).
3. Нажмите **Сохранить** и **Запустить** на вкладке «Информация».

---

## 3. Авторизация (получение токена)

После запуска надстройки откройте в браузере страницу авторизации:
```text
http://<IP_ВАШЕГО_HA>:8199/auth
```

### Способ 1: Вход по звонку (рекомендуется)
1. Введите номер телефона в формате `79001234567` и нажмите **«1. Запросить звонок»**.
2. С указанного телефона позвоните на бесплатный номер робота ЛанТы: **`8 800 222-06-68`**.
3. Дождитесь автоматического сброса вызова (звонок бесплатный).
4. Вернитесь в браузер и нажмите **«2. Я позвонил — получить токен»**.
5. Вверху страницы статус сменится на `Токен: ДА`, и отобразится количество найденных камер. Токен сохранится в `/data/lanta_auth.json` и не сбросится при перезапуске.

### Способ 2: Вход по готовому токену
Если у вас уже есть перехваченный `accessToken` из мобильного приложения «ЛанТа» или веб-кабинета `mobile.lanta-net.ru`, вставьте его в нижнее поле на странице `/auth` и нажмите **«Сохранить»**.

## 4. Где и как найти `house_id` (если камеры не определились автоматически)

Обычно надстройка сама запрашивает список ваших адресов у API и подтягивает все доступные камеры. Но если после успешной авторизации (`Токен: ДА`) счётчик показывает **`Камер: 0`** (такое бывает на некоторых типах договоров, при долевом подключении или если нужно добавить камеры соседнего корпуса/двора), укажите `house_id` вручную в настройках надстройки.

Узнать свой `house_id` можно тремя способами:

### Способ А: Через встроенную диагностику `/debug_api` (самый простой)
1. Убедитесь, что вы уже получили токен на шаге 3.
2. Откройте в браузере:
   ```text
   http://<IP_ВАШЕГО_HA>:8199/debug_api
   ```
3. В открывшемся JSON-ответе найдите блоки `getSettingsList` или `getAddressList` и поищите поле **`"houseId"`** (например, `"houseId": 7629`). Также там можно увидеть свой `"flatId"` для домофона.

### Способ Б: Через браузер на сайте `mobile.lanta-net.ru`
1. Откройте веб-кабинет `https://lanta-net.ru` на компьютере и войдите в свой аккаунт.
2. Нажмите **F12** (откроются Инструменты разработчика) и перейдите на вкладку **Сеть (Network)** → фильтр **Fetch/XHR**.
3. На сайте откройте раздел с адресами или камерами видеонаблюдения (либо обновите страницу **F5**).
4. В списке запросов найдите вызов **`all`** (`/api/cctv/all`), `getAddressList` или `getSettingsList`.
5. Кликните по запросу `/api/cctv/all` и откройте вкладку **Полезная нагрузка (Payload / Запрос)** — там будет передаваться ваш ID дома, например: `{"houseId": "7629"}`.

### Способ В: В адресной строке веб-кабинета
В некоторых разделах личного кабинета при клике на конкретный адрес или список камер дома числовой идентификатор дома отображается прямо в URL страницы в браузере.

> **Как применить:** Скопируйте найденное число, впишите его в поле `house_id` на вкладке **Конфигурация** надстройки (если домов несколько — укажите через запятую: `7629, 7630`), нажмите **Сохранить** и перезапустите надстройку.

## 5. Проверка списка камер

Откройте в браузере:
```text
http://<IP_ВАШЕГО_HA>:8199/cameras
```
Должен вернуться JSON со списком ваших камер и ссылками на потоки (`cam_id` используются далее при настройке):
```json
{
  "cameras": [
    {
      "id": 5015,
      "title": "Подъезд 1 Домофон",
      "stream": "http://<IP_ВАШЕГО_HA>:8199/stream/5015/index.m3u8",
      "ts": "http://<IP_ВАШЕГО_HA>:8199/ts/5015",
      "preview": "http://<IP_ВАШЕГО_HA>:8199/preview/5015"
    }
  ]
}
```

## 6. Настройка go2rtc для плавного видео в Home Assistant

`go2rtc` принимает MPEG-TS поток от прокси и отдаёт его в Home Assistant по WebRTC/RTSP с минимальной задержкой.

1. Если `go2rtc` ещё не установлен, установите надстройку **go2rtc** (репозиторий `https://github.com`) и запустите её.
2. Откройте в браузере автогенератор конфига:
   ```text
   http://<IP_ВАШЕГО_HA>:8199/go2rtc.yaml
   ```
3. Вы получите готовый список всех ваших камер с комментариями:
   ```yaml
   streams:
     cam_5015: http://<IP_ВАШЕГО_HA>:8199/ts/5015 # Подъезд 1 Домофон
     cam_5016: http://<IP_ВАШЕГО_HA>:8199/ts/5016 # Двор
   ```
4. Скопируйте эти строки в конфигурацию `go2rtc` (`go2rtc.yaml`), сохраните и перезапустите `go2rtc`.
   *(Примечание: если `go2rtc` и прокси работают на одном хосте Home Assistant OS, в качестве IP можно оставить локальный IP вашего сервера HA или внутренний шлюз Docker `172.30.32.1`).*
5. Проверьте поток в веб-интерфейсе `go2rtc`: `http://<IP_ВАШЕГО_HA>:1984`.

## 7. Добавление камер на дашборд Home Assistant

### Вариант А: WebRTC Camera (рекомендуется, минимальная задержка)
Установите карточку **WebRTC Camera** через HACS и добавьте на дашборд:
```yaml
type: custom:webrtc-camera
url: cam_5015
```
*(или укажите полный RTSP-путь: `rtsp://<IP_ВАШЕГО_HA>:8554/cam_5015`).*

### Вариант Б: Стандартная интеграция Generic Camera
1. **Настройки** → **Устройства и службы** → **Добавить интеграцию** → **Generic Camera**.
2. Укажите URL источника потока: `rtsp://<IP_ВАШЕГО_HA>:8554/cam_5015` и URL статичной картинки: `http://<IP_ВАШЕГО_HA>:8199/preview/5015`.

### Вариант В: Только обновляющиеся снимки (MJPEG IP Camera)
Если живое видео не требуется и нужны только превью без нагрузки на процессор:
1. Добавьте интеграцию **MJPEG IP Camera**.
2. В поле **Still Image URL** укажите: `http://<IP_ВАШЕГО_HA>:8199/preview/5015`.

## 8. Управление «Гостевым доступом» домофона (автооткрытие на 1 час)

Прокси умеет включать и выключать режим автоматического открытия двери домофона на 1 час (без звонка в квартиру) через эндпоинт `/guest_access`. `flatId` определяется автоматически по первой квартире в аккаунте (при наличии нескольких квартир можно передавать `?flatId=12345`).

Пример готового переключателя и команд для `configuration.yaml` в Home Assistant (замените `<IP_ВАШЕГО_HA>` на локальный IP вашего сервера или `localhost`):

```yaml
rest_command:
  lanta_guest_on:
    url: "http://<IP_ВАШЕГО_HA>:8199/guest_access"
    method: POST
    content_type: "application/json"
    payload: '{"enable": true}'
  lanta_guest_off:
    url: "http://<IP_ВАШЕГО_HA>:8199/guest_access"
    method: POST
    content_type: "application/json"
    payload: '{"enable": false}'

sensor:
  - platform: rest
    name: "LanTa Guest Access Status"
    unique_id: lanta_guest_access_status
    resource: "http://<IP_ВАШЕГО_HA>:8199/guest_access"
    method: GET
    value_template: "{{ value_json.is_active }}"
    json_attributes:
      - autoOpen
      - flatId
    scan_interval: 60

template:
  - switch:
      - name: "Домофон: Гостевой доступ (1 час)"
        unique_id: lanta_guest_access_switch
        state: "{{ is_state('sensor.lanta_guest_access_status', 'True') }}"
        icon: >-
          {% if is_state('sensor.lanta_guest_access_status', 'True') %}
            mdi:door-open
          {% else %}
            mdi:door-closed-lock
          {% endif %}
        turn_on:
          - action: rest_command.lanta_guest_on
          - delay: 1
          - action: homeassistant.update_entity
            target:
              entity_id: sensor.lanta_guest_access_status
        turn_off:
          - action: rest_command.lanta_guest_off
          - delay: 1
          - action: homeassistant.update_entity
            target:
              entity_id: sensor.lanta_guest_access_status
```

## Решение проблем

- **Камер 0 после авторизации:** проверьте `http://<IP_ВАШЕГО_HA>:8199/debug_api` — если статус `401`, повторите вход на `/auth`. Если статус `200`, но камер нет — пропишите `house_id` вручную по инструкции из пункта 4.
- **Потоки не открываются в go2rtc:** убедитесь, что в `go2rtc.yaml` указан доступный для контейнера IP-адрес вашего Home Assistant, а имена камер совпадают с выводом `/go2rtc.yaml` (`cam_<id>`).
- **Ошибка 403 при просмотре:** ссылки на потоки привязаны к внешнему IP-адресу и времени жизни токена камеры. Надстройка обновляет их сама при 403 ошибке, либо вы можете принудительно обновить их POST-запросом на `http://<IP_ВАШЕГО_HA>:8199/refresh` или перезапуском надстройки.
