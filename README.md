# Lanta Camera Proxy

Прокси-сервер для камер видеонаблюдения и домофонов провайдера **ЛанТа** (`mobile.lanta-net.ru`)
с авторизацией по звонку или токену. Версия **2.1.0**.

## Возможности

- Проксирование HLS / MPEG-TS потоков камер (через `ffmpeg`) и генерация конфига для `go2rtc`.
- Авторизация по звонку на `8 800 222-06-68` или готовому токену (`/auth`).
- **Домофон через MQTT Auto-Discovery** — устройство «Домофон LanTa» появляется в
  Home Assistant автоматически (без правки `configuration.yaml`):
  - переключатели: гостевой доступ, трубка (КМС), видеозвонки, вход по коду;
  - сенсор последнего события (с атрибутами `person`, `is_known`, `is_duplicate_pass`, `door`, `preview_url` и т.д.);
  - бинарные сенсоры: открытие по коду, звонок, статус токена;
  - камера с JPEG последнего кадра (для пуш-уведомлений с фото).
- Журнал событий домофона (`/api/address/plog`) со склейкой фото, определением человека
  по именам и анти-спам дедупликацией прохода (двор → подъезд → лифт).
- Страница настройки имён `/people` (лица / RFID-ключи / телефоны).

## Быстрый старт

1. Установите надстройку как локальное дополнение.
2. Запустите и пройдите авторизацию: `http://<IP_ВАШЕГО_HA>:8199/auth`.
3. Настройте имена: `http://<IP_ВАШЕГО_HA>:8199/people`.
4. Устройство «Домофон LanTa» появится в интеграции **MQTT** автоматически.

## Примечания

- Токен хранится в `/data/lanta_auth.json`, имена — в `/data/lanta_people.json`.
- Часовой пояс событий — МСК (`UTC+3`).
- Требуется запущенный MQTT-брокер (например, надстройка **Mosquitto**).
