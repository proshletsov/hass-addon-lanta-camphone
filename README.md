# Lanta Camera Proxy — Home Assistant Add-on

Прокси-сервер для камер видеонаблюдения и домофонов провайдера **ЛанТа** (`mobile.lanta-net.ru`) с авторизацией по звонку или токену.

> **Благодарности:** Проект является переработанным форком оригинальной надстройки [amatsnev/hass-addon-lanta-cam]([https://github.com](https://github.com/amatsnev/hass-addon-lanta-cam)) (автор — [@amatsnev]([[https://github.com](https://github.com/amatsnev/hass-addon-lanta-cam](https://github.com/amatsnev)))). В этой версии осуществлён переход со старого веб-портала на мобильное API ЛанТы с поддержкой беспарольного входа и управления домофоном.

## Возможности

- **Удобная авторизация** — встроенный веб-интерфейс (`/auth`) для входа по входящему/исходящему звонку или готовому Bearer-токену
- **Автоопределение камер** — домофоны, дворовые, внутренние и лифтовые камеры подтягиваются автоматически (с возможностью ручного указания `house_id`)
- **Фоновое обновление** — автоматическое обновление списка камер и ссылок каждые 1.5 часа и при ошибках `403`
- **Совместимость с go2rtc** — генерация конфига и конвертация потоков в MPEG-TS через `ffmpeg`
- **Гостевой доступ** — управление режимом автооткрытия домофона через REST API (`/guest_access`)
