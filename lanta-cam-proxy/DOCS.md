# Lanta Camera Proxy — Документация

Прокси-сервер для камер видеонаблюдения и домофонов провайдера **ЛанТа** (`mobile.lanta-net.ru`) с авторизацией по звонку или токену.

> Форк оригинальной надстройки [amatsnev/hass-addon-lanta-cam]([https://github.com](https://github.com/amatsnev/hass-addon-lanta-cam)). Полное руководство с примерами карточек и автоматизаций смотрите в файле [INSTALL.md]([https://github.com](https://github.com/proshletsov/hass-addon-lanta-camphone/blob/main/INSTALL.md)).

---

## 1. Параметры конфигурации (вкладка «Конфигурация»)

- **`phone`** *(необязательно)* — номер телефона от договора ЛанТа (например, `79001234567`). Можно не указывать здесь и ввести позже на странице авторизации.
- **`bearer_token`** *(необязательно)* — готовый токен (UUID без слова `Bearer`). Заполняется только если вы не хотите входить по звонку.
- **`house_id`** *(необязательно)* — ID вашего дома (или несколько через запятую: `7629, 7630`). При первом запуске оставьте пустым — надстройка попробует определить дом автоматически.
- **`refresh_interval`** — интервал фонового обновления ссылок и токенов камер в секундах (по умолчанию `5400` = 1.5 часа).

---

## 2. Быстрый старт и авторизация

1. Запустите надстройку и откройте в браузере веб-интерфейс авторизации:
   ```text
   http://<IP_ВАШЕГО_HA>:8199/auth
   ```
2. **Вход по звонку:**
   - Введите номер телефона (`79001234567`) и нажмите **«1. Запросить звонок»**.
   - Позвоните с этого номера на бесплатный номер робота ЛанТы: **`8 800 222-06-68`** и дождитесь автоматического сброса.
   - Нажмите **«2. Я позвонил — получить токен»**.
3. Статус вверху страницы изменится на **`Токен: ДА`** и появится количество загруженных камер. Токен сохраняется в `/data/lanta_auth.json` и сохраняется после перезапуска.

---

## 3. Если после входа показывает «Камер: 0» (поиск `house_id`)

На некоторых типах договоров API не отдаёт список домов автоматически. В этом случае укажите `house_id` вручную на вкладке **Конфигурация**:

1. Откройте `http://<IP_ВАШЕГО_HA>:8199/debug_api` после получения токена и поищите поле `"houseId"` в ответе.
2. Либо войдите в веб-кабинет `https://lanta-net.ru` с компьютера, откройте Инструменты разработчика (**F12** → **Network / Сеть** → **Fetch/XHR**), перейдите в раздел камер и посмотрите значение `houseId` в запросе `/api/cctv/all`.
3. Впишите найденное число в поле `house_id`, сохраните настройки и перезапустите надстройку.

---

## 4. Подключение к go2rtc

1. Откройте в браузере готовый список потоков:
   ```text
   http://<IP_ВАШЕГО_HA>:8199/go2rtc.yaml
   ```
2. Скопируйте сгенерированный блок `streams:` в конфигурацию надстройки **go2rtc**, сохраните и перезапустите `go2rtc`.
3. Добавьте камеры на дашборд через WebRTC Camera (`url: cam_<id>`) или интеграцию Generic Camera (`rtsp://<IP_ВАШЕГО_HA>:8554/cam_<id>`).

---

## 5. Основные HTTP-эндпоинты (порт `8199`)

| Путь | Метод | Описание |
|------|-------|----------|
| `/auth` | `GET` | Веб-страница авторизации по звонку или токену |
| `/cameras` | `GET` | JSON-список всех найденных камер и ссылок на потоки |
| `/go2rtc.yaml` | `GET` | Готовый конфиг потоков (`cam_<id>`) для вставки в `go2rtc` |
| `/ts/{cam_id}` | `GET` | Поток MPEG-TS через `ffmpeg` (основной для `go2rtc`) |
| `/stream/{cam_id}/index.m3u8` | `GET` | Проксированный оригинальный HLS-поток |
| `/preview/{cam_id}` | `GET` | JPEG-превью (скриншот) камеры |
| `/guest_access` | `GET` / `POST` | Статус и переключение автооткрытия домофона на 1 час (`{"enable": true/false}`) |
| `/refresh` | `POST` | Принудительное обновление списка камер и токенов |
| `/debug_api` | `GET` | Диагностический вывод ответов API (`houseId`, `flatId`) |
